# Sparkline Faces

Watchfaces that share one top section — the "main watchface info" from
[Solfarer](../Solfarer): the clock, step count, distance and heart rate (with
hours slept on a shake), the date and temperature, and a sparkline of the past
hour's activity. On Emery all of that fits in the top 56 of 228 rows.

The rest of the screen is the experiment. Each subdirectory takes that band as
given and does something different with the other three quarters.

**Emery only** while an idea is being tried. Other platforms get a layout pass
once something is worth publishing.

| Face | What it does with the screen |
| --- | --- |
| [TeaScene](TeaScene) | A Chinese gongfu tea table below the band, recoloured for the time of day |
| [Sparkline](Sparkline) | No band at all — the same information given all 228 rows, sparkline along the bottom edge |
